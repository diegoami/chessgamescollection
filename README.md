# chessgamescollection

diegoami's chess.com games, Stockfish analysis, and the published GitHub pages built from them.

This repo holds data only. The scripts that generate `analyzed_games/` and `docs/` from
`daily_games/` live in a separate repo, [pgn-postmortem](https://github.com/diegoami/pgn-postmortem),
checked out as a sibling directory:

```
projects/
├── pgn-postmortem/         (scripts, venv, requirements.txt)
└── chessgamescollection/   (this repo)
```

pgn-postmortem points at this repo via `CHESS_DATA_DIR=../chessgamescollection` in its local `.env`
file (see its `.env.example`) — that's local config, not a hardcoded default, so if you're setting
this pairing up fresh, configure `.env` there yourself first.

## Layout

- `daily_games/<id>.pgn` — raw PGNs as downloaded from chess.com, one file per game, numbered
  sequentially. This is the only directory meant to be hand-edited (drop new PGN exports in here).
- `analyzed_games/<id>.pgn` — same games, independently re-analyzed with Stockfish. Generated by
  `scripts/analyze_games.py` in pgn-postmortem — do not hand-edit.
- `docs/` — the published GitHub pages (main index + one page per game, with board diagrams).
  Generated by `scripts/publish_games.py` in pgn-postmortem — do not hand-edit.

## Regenerating analyzed_games/ and docs/

From the pgn-postmortem checkout (with `.env` configured as above):

```bash
scripts/update_games.sh
```

or the two steps individually — see pgn-postmortem's README and its `publish-games` skill for the
full workflow.

## The book (`book/`)

`book/` is built with the [pgn-postmortem](https://github.com/diegoami/pgn-postmortem) library
(installed with pip, not the sibling scripts above) and published with GitHub Pages at
https://diegoami.github.io/chessgamescollection/:

- `book/games/`: one normalized PGN per game, read from
  [DA_chessgames](https://github.com/diegoami/DA_chessgames). The first batch is the
  over-the-board games.
- `book/analyzed/`: the same games analyzed by Stockfish. They are kept in git so the analysis is
  never redone.
- `book/site/`: the generated site, with one article per game and "what would you play?" questions
  at the critical moments. Don't edit it; rebuild it.
