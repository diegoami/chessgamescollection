# chessgamescollection

diegoami's chess.com games, Stockfish analysis, and the published GitHub pages built from them.

This repo holds data only. The scripts that generate `analyzed_games/` and `docs/` from
`daily_games/` live in the [chess_with_claude](https://github.com/diegoami/chess_with_claude) repo,
which by default expects this repo checked out as a sibling directory:

```
projects/
├── chess_with_claude/   (scripts, venv, requirements.txt)
└── chessgamescollection/  (this repo)
```

## Layout

- `daily_games/<id>.pgn` — raw PGNs as downloaded from chess.com, one file per game, numbered
  sequentially. This is the only directory meant to be hand-edited (drop new PGN exports in here).
- `analyzed_games/<id>.pgn` — same games, independently re-analyzed with Stockfish. Generated by
  `scripts/analyze_games.py` in chess_with_claude — do not hand-edit.
- `docs/` — the published GitHub pages (main index + one page per game, with board diagrams).
  Generated by `scripts/publish_games.py` in chess_with_claude — do not hand-edit.

## Regenerating analyzed_games/ and docs/

From the chess_with_claude checkout:

```bash
.venv/bin/python scripts/analyze_games.py
.venv/bin/python scripts/publish_games.py --source analyzed_games
```

Both default to this repo via `../chessgamescollection` (a sibling directory); pass `--data-dir` to
either script to point elsewhere.

See chess_with_claude's README and its `publish-games` skill for the full workflow.
